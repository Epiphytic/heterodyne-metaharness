# Source (OpenShell 0.1.2, crates/openshell-sandbox/src/network_broker.rs): a seccomp user-notification
# broker traps INET socket()/connect()/sendto(). create_socket admits only TCP/UDP (else EPROTONOSUPPORT);
# a policy-denied TCP connect and a non-DNS UDP connect answer EACCES (tcp_denial_errno); a destination-bearing
# non-DNS UDP sendto answers EDESTADDRREQ (classify_send). The broker answers before the kernel would, so
# ENETUNREACH (shown by the plain --network=none control) is never observable inside OpenShell.
# The workload netns has only lo (podman NetworkMode=none: the kernel fence). Egress exists only through the
# supervisor container (NetworkMode=host), which runs the policy proxy: the broker holds each connect(2) until
# the supervisor decides, then relays an allowed one to it (PendingTcpOpen). The 1.1.1.1 / 2606:4700:4700::1111 targets are public probe addresses.
