# Context hygiene

SOUL preserves personality with a small active-spec pointer; MEMORY preserves current
facts, USER personal preferences. Remove duplicate anecdotes and stale pending-work
claims, without assuming historical project milestones are complete.

Cleanup uses explicit reviewed paths and hashes; quarantine obsolete skill frameworks
and legacy relay guidance outside active skills, recall, brain mirrors and repositories.
Never select content for deletion merely because it contains OpenClaw or a username.
Back up with SHA-256 verification before mutation. Repeating a successful operation
must be a no-op; drift must stop, not overwrite newer content.

Native session archiving affects UI only and DOES NOT exclude recall. Historical
transcript purge requires a consistent SQLite backup, verified export, ended detached
sessions, current routing/lease/delegation/delivery/harness checks, and native deletion
with expected_delete_ids. Preserve compression ancestors, children, active sessions
and tool-call chains. Do not deduplicate individual messages by text equality.
Do not restore whole live databases over new activity. Private backups are never pushed.
See [change evidence](changes.md).
