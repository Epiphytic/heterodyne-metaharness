2. [BLOCKING] **docs/design/acp-adapter-note.md:84 — The denial fallback misses valid option sets.** The cancellation fallback is conditional on both `allow_once` and `reject_once` being absent. A request offering `allow_once` but no `reject_once` therefore has no defined response for hard denial, escalation or a `wsd` outage. ACP does not require agents to offer a rejection option; selecting an invented ID would violate the [permission response contract](https://agentclientprotocol.com/protocol/v1/tool-calls#requesting-permission). **Fix:** whenever the decision requires denial and no `reject_once` exists, cancel the turn and answer pending requests with `cancelled`, regardless of whether `allow_once` exists. Apply this rule to every denial row.
