This is the next implementation slice of the independently reviewed, human-approved owner recovery design (`daf3`, Hermes PR301, approved design head 9e957f2e69a08203c3a8b0dd942e4d557a4c0db7). `SandboxRuntime.reconcile_session(original_record)` uses the actual retained manager owner and exact original immutable record. A live executor returns LIVE without effects. Missing death proof is a hold, never permission derived from elapsed time. A regular, bounded, strictly matching reaper marker with a valid expired deadline and an explicitly retained dead pane are required. Exact original record, raw marker bytes and SHA256, pane identity/PID/death/exit fields and a bounded pane tail are durably written before the stopping journal or normal `_end` cleanup can delete the source evidence. No new operation ID or launch is invented.

The same original record and receipt permit continuation after a receipt-only crash, partial STOPPING cleanup, or failed lifetime WIP. An unrelated transitional record or changed generation is refused. Normal Product cleanup, watch/taint fanout, private Git landing and lifetime WIP are retained. ENDED is reported only after exact-generation readback, authentic lifetime cause, absent resources including late-create protection/reapers, and no unlanded/WIP obligation. Read/list/Git failures remain holds. This API does not acquire a manager owner, restore all sessions, launch, send inputs, replay an Ask, or modify native approval/task ownership.

Hermes caller wiring remains separate work: durable ending and launch fences, readonly native admission/profile/account/model/ancestry qualification, then supported root installer and paired native postlaunch enrollment. Product cannot recover account/model pins absent from SessionRecord. This source is not deployed and does not switch the actual Claude admin executor to Codex. Original UNKNOWN effects remain protected.
