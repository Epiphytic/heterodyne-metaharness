1. [BLOCKING] `src/heterodyne/sandbox/channel.py:288–307` — Timeout, read error and clean EOF all become `b""`; after `done`, each sets `run.finished = True`. ACK failure is also ignored. An in-memory control that sends passing checks and `done`, then raises `TimeoutError` without EOF, produces a passing verdict. **Fix:** distinguish EOF from timeout, error and forced shutdown; require successful ACK and clean EOF. Add negative tests for each termination path.

2. [BLOCKING] `src/heterodyne/sandbox/openshell_selftest.py:229–235` — `_until` tests completion before checking the deadline. If its sleep or scheduling crosses the deadline and the probe finishes meanwhile, it returns `True`; the new timeout latch therefore still permits late completion. A clock control with a one-second deadline and completion at two seconds confirms this. **Fix:** enforce a monotonic deadline when accepting completion, preferably using a channel completion timestamp. Test completion during the final polling sleep. This defect is inherited from the plan.

3. [BLOCKING] `src/heterodyne/sandbox/channel.py:241–242` — The acknowledged SO_PEERCRED-to-`pidfd_open` race remains: a successor can be pinned while the socket contains the original peer’s results. Requiring that successor to verify does not establish that it authored those results. Task 9A’s namespace checks do not close this identity gap, so it is not acceptable for this proof of concept. **Fix:** obtain the credential-associated pidfd through `getsockopt(SOL_SOCKET, 77, 4)`, unpack one native integer, and retain the liveness checks around verification. This is a cheap, sound identity fix on Linux 6.17; fail closed if unavailable and close the descriptor on every path. The [kernel implementation introduces SO_PEERPIDFD for this purpose](https://git.zx2c4.com/linux-rng/commit/arch/mips/include/uapi/asm/socket.h?id=7b26952a91cf65ff1cc867a2382a8964d8c0ee7d). Add a replacement-before-pinning control; current tests kill the peer only after pinning. The underlying gap is inherited from the plan.
